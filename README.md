# DPIShortcut

A lightweight Windows utility for quickly switching display scaling (DPI) through global keyboard shortcuts.

## Features

- Runs quietly in the Windows system tray.
- `Alt + Z` — Switch display scaling to **100%**.
- `Alt + X` — Switch display scaling to **175%**.
- Right-click the system tray icon to open the context menu.

## Usage

1. Download `DPIShortcut.exe` from the [Releases](https://github.com/ICMILE/Setdpi/releases) page.
2. Run `DPIShortcut.exe`.
3. The application will run in the system tray.
4. Use the keyboard shortcuts to switch display scaling.

## Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Alt + Z` | Set DPI scaling to 100% |
| `Alt + X` | Set DPI scaling to 175% |

## Requirements

- Windows
- No Python or additional runtime installation required.
